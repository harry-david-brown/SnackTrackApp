# Mockup-fidelity UX deviations to review

This overhaul intentionally treats the approved onboarding and ads/upsell mockups as the visual baseline. The following choices should be considered when SnackTrack’s UI guideline is updated after product review:

- Authenticated setup and import are full-screen journeys, not cards embedded in a management hub.
- Expressive pages use 28–39px medium/semi-bold headings instead of heavy 800/900-weight headings.
- The recommended setup action uses a large green-tinted choice surface; secondary methods are intentionally quieter.
- Wrapped uses screen-specific lagoon and indigo/gold gradients, Fredoka headlines, story progress rails, and glassy evidence cards.
- Coverage and profile summaries use dark-green composition cards with light text rather than standard white cards.
- Native ads have placement-specific layouts: a full Home card and compact History insertion.
- Settings and data-management rows use grouped, compact navigation patterns with 44-point minimum actions.
- Semantic warning, error, and success colors remain unchanged even when a screen otherwise departs from the previous visual system.
